# Contributing

Thanks for your interest in contributing to PolicyMind AI!

## Getting started
1. Fork the repo and clone your fork
2. Create a virtual environment and install dependencies:
1
3. Create a branch: `git checkout -b feature/my-feature`

## Development guidelines
- Economic/demographic figures used in simulations must be user-sourced,
  never fabricated
- Keep simulation logic in app/simulation/, RAG logic in app/rag/,
  stakeholder graph logic in app/graph/

## Submitting changes
1. Commit with a clear message
2. Push to your fork and open a pull request against main
